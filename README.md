* 🚕 [**Tour Booking App**](https://github.com/Illya1123/Travel-Web.git) – React Native + ReactJS & Vite + MoMo + MongoDB + Node.js
  ✈️ Dự án phát triển hệ thống **website và ứng dụng di động** phục vụ nhu cầu du lịch toàn diện.
  🔹 Cho phép người dùng:

  * 📅 Đặt tour có sẵn từ nhiều nhà cung cấp
  * 🏨 Tìm và đặt khách sạn theo điểm đến
  * ✈️ Mua vé máy bay nhanh chóng
  * 🚗 Thuê xe tự lái hoặc xe du lịch
  * 📰 Đọc và chia sẻ tin tức, kinh nghiệm du lịch
    🧩 Công nghệ sử dụng: MERN stack (MongoDB, Express, React, Node.js), Redux, Vite, thanh toán tích hợp MoMo

* 🧠 [**Scene Classification with GNN**](https://github.com/Illya1123/IS353_DoAn.git) – PyTorch Geometric + Intel Dataset + SLIC + Delaunay
  Dự án này tập trung vào bài toán phân loại ảnh cảnh vật từ dataset **Intel Image Classification**.
  🔍 Thay vì sử dụng CNN thuần túy, dự án áp dụng **Graph Neural Network (GNN)** để khai thác mối quan hệ không gian giữa các siêu điểm ảnh (superpixels).
  ✅ Mục tiêu: phân loại chính xác các cảnh như **rừng**, **biển**, **đô thị**, **núi**, **băng tuyết**,... bằng cách biểu diễn ảnh dưới dạng đồ thị và học đặc trưng từ các nút.
  🛠️ Công nghệ chính: PyTorch Geometric, SLIC, Delaunay Triangulation, Feature Engineering

* 😃 [**Sentiment Analysis from TikTok Comments**](https://github.com/Illya1123/IE403_DoAn.git) – Streamlit + Machine Learning + Deep Learning + Tự động gán nhãn
  📊 Hệ thống phân tích cảm xúc từ **bình luận video TikTok**.
  🔍 Tự động crawl bình luận từ URL video TikTok, tiền xử lý tiếng Việt, gán nhãn dữ liệu bằng mô hình tự động.
  ✅ Kết hợp nhiều mô hình học máy và học sâu như: Logistic Regression, Random Forest, Transformer (PhoBERT), ...
  🛠️ Công nghệ sử dụng: Scikit-learn, PyTorch, Streamlit, Underthesea, Request
